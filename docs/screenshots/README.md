Estas imágenes documentan la web; no acreditan instalaciones reales ni ejecución de la GUI en Windows. Al cambiar la interfaz, vuelve a capturarlas y comprueba que no incluyan datos privados, nombres reales de instaladores internos ni tokens. Conserva las atribuciones de las marcas recogidas en [ASSETS.md](../../ASSETS.md).
